پروژه اندروید ماشین‌حساب امید - نسخه ۱.۲

این بسته پروژه قابل ساخت است و APK آماده درون آن نیست.
برای ساخت: تمام محتویات این پوشه (از جمله پوشه مخفی .github) را در ریشه مخزن GitHub قرار دهید و Commit کنید. سپس در Actions اجرای workflow با نام Build Omid Android APK را بررسی کنید. در پایان اجرای موفق، از بخش Artifacts فایل Omid-Calculator-1.2-debug-apk را دانلود کنید.

تماس سیم‌کارتی: برنامه با مجوز CALL_PHONE تماس را آغاز می‌کند؛ اندروید ممکن است رابط تماس سیستم را نمایش دهد. این نسخه شماره‌گیر پیش‌فرض اندروید نیست و رابط مکالمه کاملاً داخل برنامه قرار نمی‌گیرد.
